# Customer Segmentation and Churn Prediction

Axlero Solutions Data Analytics Internship, Project 1 (Retail & E-commerce).

Online retailers spend heavily to win customers but often can't tell which ones are valuable or which are about to leave. This project analyses about one million transactions from the UCI Online Retail II dataset, groups customers into segments using RFM (Recency, Frequency, Monetary) and K-Means clustering, predicts which customers are likely to churn in the next 90 days, and presents the results in an interactive Tableau dashboard with marketing recommendations for each segment.
